# 5.8GHz FPV スキャナー（XIAO ESP32-C5 + XIAO ESP32-S3）

XIAO ESP32-C5 を ESP-SDR の受信専用機として使い、XIAO ESP32-S3 が 2.4GHz の
Wi-Fi アクセスポイントと Web サーバーになって、スマホのブラウザに 5GHz 帯の
スペクトラムを表示します。

```
[XIAO ESP32-C5]  --UART 2Mbaud-->  [XIAO ESP32-S3]  ~~2.4GHz Wi-Fi~~>  スマホのブラウザ
 ESP-SDR 本家ファーム               このプロジェクト（PlatformIO）
 5GHz を受信・FFT                   周波数スイープ・合成・Web表示
```

C5 は 1 回に約 30MHz 幅（40MS/s 設定時）しか見られないため、S3 が C5 の周波数を
順に切り替えて（既定の 5650〜5850MHz なら 7 ステップ）スペクトラムをつなぎ合わせます。

### スキャン範囲（スパン）とステップ

| ステップ幅（画面の選択） | C5 のサンプルレート | アナログフィルタ | 既定 200MHz のステップ数 | FFT 1 ビンの幅 |
| --- | --- | --- | --- | --- |
| 40 MHz（既定） | 80 MS/s | 44 MHz | 5 | 39 kHz |
| 30 MHz | 80 MS/s | 32 MHz | 7 | 39 kHz |
| 15 MHz | 40 MS/s | 16 MHz | 14 | 20 kHz |
| 7.5 MHz | 20 MS/s | 11 MHz | 27 | 10 kHz |

各ステップでは LO の周りのステップ幅ぶんだけを使い、サンプルレートをその 2 倍以上、
アナログフィルタをステップ幅程度にしています。ステップの外にある強い電波が
折り返して（エイリアス）別の周波数に映り込むのを防ぐためです。

受信設定の初期値: ステップ幅 40MHz、滞在 25ms、検波 最大値、ゲイン 40、dBm 補正値 0.0dB。
強い電波の映り込みを減らしたいときは、ステップ幅 30MHz（フィルタ 32MHz）を選んでください。

- スパンは開始・終了とも 2300〜6000MHz の範囲で、5MHz 以上の幅を指定できます。
- 画面に送る点数は常に 1000 点です（200MHz なら 1 点 0.2MHz、各点はその中の最大値）。
- 1 スイープの時間はおおよそ「ステップ数 ×（周波数切替・校正 + 滞在時間）」です。
  ステップ数を減らす（スパンを狭める・レートを上げる）と更新が速くなります。
- 画面上部の「適用中」の行に、実際にスイープしている設定（範囲、レート、ステップ数、
  滞在時間、検波、ゲイン、補正値、1 スイープの時間）を表示します。「適用」を押すと
  現在のスイープを中断してすぐ新しい設定で測り直し、反映されるまで「変更を反映中…」と
  表示します。範囲外のゲインは C5 に拒否され、自動に戻してエラーを表示します。

## 1. 配線

| XIAO ESP32-C5 | XIAO ESP32-S3 |
| --- | --- |
| D6 (GPIO11, TX) | D7 (GPIO44, RX) |
| D7 (GPIO12, RX) | D6 (GPIO43, TX) |
| GND | GND |
| 5V（または 3V3） | 5V（または 3V3） |

TX と RX はたすき掛けです。C5 は無線起動時に電流が増えるので、電源は USB など
余裕のあるものから取ってください。C5 には 5GHz 対応のアンテナを付けてください。

## 2. XIAO ESP32-C5 の書き込み（1 回だけ）

本家のブラウザインストーラーで ESP-SDR を書き込みます。改造は不要です。

1. PC の Chrome / Edge で <https://espargos.net/espsdr/app/flash.html> を開く
2. C5 を USB 接続し、**ESP32-C5** のファームウェアを選んで書き込む

書き込み後、C5 は USB と UART（D6/D7, 2Mbaud）の両方でコマンドを受け付けます。

## 3. XIAO ESP32-S3 の書き込み（PlatformIO）

1. Visual Studio Code に PlatformIO 拡張を入れる
2. このフォルダ `fpv_scanner_s3` を「フォルダーを開く」で開く
3. Wi-Fi の初期値は SSID `FPV-Scanner`、パスワード `fpv-sa00` です（公開済みの値）。
   変更する場合は `src/config.h` の `AP_SSID` / `AP_PASSWORD` を書き換えます
   （パスワードは 8 文字以上）
4. S3 を USB 接続し、PlatformIO の「Upload」（→ボタン）で書き込む

書き込みで `No serial data received` などのエラーが出るとき:

- **C5 との配線（D6/D7）を外すか、C5 の電源を切ってから書き込む。**
  S3 の D6/D7 は書き込み用の UART0 と同じピンで、C5 からのデータが書き込みを妨げます
- それでも失敗する場合は、S3 の BOOT ボタンを押したまま RESET ボタンを押して離し、
  BOOT を離してから Upload する（書き込み後は RESET を押す）
- USB ハブを使わず PC に直接つなぎ、データ通信対応のケーブルを使う

## 4. 使い方

1. 両方のボードに電源を入れる
2. スマホで Wi-Fi `FPV-Scanner` にパスワード `fpv-sa00` で接続する
3. キャプティブポータルで画面が自動的に開きます
   - iPhone: 接続するとログイン画面としてそのまま開きます
   - Android: 「ネットワークにログイン」の通知をタップします。
     「インターネットに接続されていません」と出たら「このまま接続」を選んでください
   - 開かない場合はブラウザで <http://192.168.4.1/> を開きます（どの URL を開いても
     この画面に転送されます）

画面の構成（上から）:

- **スペクトラム**: 横軸 MHz、縦軸 dBm。チェックしたバンドの FPV チャネルを縦線で表示。
  保存したノイズレベルを灰色の線で重ねて表示します
- **マーカー 4 個 (M1〜M4)**: ボタンでアクティブマーカーを選び、グラフかすぐ下の
  チャネル表をタップして配置。周波数・受信レベル (dBm)・最寄りの FPV チャネルを表示。
  「ピークへ」で最大点に移動。「保存」でマーカー位置を保存し、次回起動時も同じ位置に
  なります。数値で表示するのはマーカーのレベルだけです
- **FPV チャネル表**: Band A/B/E/F/R × CH1〜8 の周波数。タップしたセルの周波数に
  アクティブマーカーを置きます（マーカーのあるセルは枠付き）。グラフに表示する
  バンドを選んで「適用」
- **スパン**: 開始/終了、または中心/幅で指定し「適用」。プリセットと
  「アクティブマーカー ±20MHz」は入力欄に入るだけなので、確認して「適用」を押します
- **受信設定**: ステップ幅、滞在時間、検波（最大値/平均）、ゲイン
  （-1 = 自動 AGC、2〜上限 = 固定）、dBm 補正値。「適用」で反映
- **ノイズレベル**: 「今のノイズを保存」で、直近の平均トレースをその場所のノイズとして
  保存します。VTX を止めてしばらく表示させてから押してください。ゲイン・ステップ幅・
  検波を変えると条件が合わなくなるため、保存したノイズは自動で消去されます
- **表示**: ピークホールド、平均、縦軸の上限と範囲。「適用」で反映

「適用」「保存」を押した設定（スパン、受信設定、補正値、バンド表示、表示設定、
マーカー位置）と保存したノイズは S3 本体に保存され、次に電源を入れたときもその設定で
起動します。
変更して未適用のときは「適用」ボタンが黄色の枠になります。

### dBm 補正値の合わせ方

表示は「C5 の ADC 基準のレベル (dBFS) + 補正値」です。

1. ゲインを固定する（例: 40）。自動 (AGC) では基準が変わり dBm がずれます
2. 出力のわかっている送信機（例: 25mW = 14dBm の VTX）を、わかっている距離・
   アンテナで受ける。または信号発生器を使う
3. マーカーをその周波数に置き、表示が期待する dBm になるよう補正値を変えて「適用」

精度は目安です。ゲインやステップ幅を変えたら補正値も合わせ直してください。

## 注意点

- dBm は補正値で合わせた目安です。校正された測定器の値ではありません。
- ゲイン自動（AGC）ではステップごとに感度が変わり、つなぎ目で段差が出ることが
  あります。dBm で比べるときはゲインを固定してください。
- **入力が強すぎると受信機が飽和し、実在しない位置に電波が表示されます。** 近くの VTX を
  測るときはゲインを下げるか距離をとってください。グラフの下に「入力が強すぎる可能性」
  と出たら飽和の目安です（1 ビンあたり約 -30dBFS 以上）。
- 本家の実測で C5 の受信が確認されているのは 5180〜5800MHz です。**5895MHz を
  超える周波数（E6〜E8、R8 など）は実機で受信できるか確認してください。**
- 既定の 5650〜5850MHz には入らないチャネルがあります（A1 5865、B8 5866、
  E4 5645、E5〜E8、F7 5860、F8 5880、R7 5880、R8 5917）。プリセット「5640-5950」で全チャネルを
  表示できます（ステップが増えるぶん更新は遅くなります）。
- スナップショット方式のため、連続受信ではありません（各ステップで約 25ms ずつ受信）。

## ファイル構成

- `platformio.ini`: PlatformIO 設定（board = seeed_xiao_esp32s3, Arduino）
- `src/config.h`: Wi-Fi 名・パスワード、UART ピン、初回起動時のスパン
- `src/sdr_link.*`: ESP-SDR の UART プロトコル（`SYNC`, `FREQ`, `SPEC`）クライアント
- `src/main.cpp`: スイープ処理、設定とノイズの保存（NVS）、キャプティブポータル（DNS 53）、
  Web サーバー (80)、WebSocket (81)
- `src/index_html.h`: スマホ用の画面（HTML/JavaScript）
